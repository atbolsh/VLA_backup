Save scenes from the Gradio editor (`Save scene`). They land in `scenes/<name>.npz` plus a JSON sidecar.

This folder is for hand-picked examples you want in git. After you have a box up:

1. Open a LIBERO task.
2. Move objects with the sliders.
3. Save as e.g. `bowl_on_left`.
4. Copy `scenes/bowl_on_left.npz` and `.json` here if you want them versioned.

Do not commit huge binaries unless you mean to.
